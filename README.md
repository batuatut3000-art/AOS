# AOS — A Hobby Operating System

AOS is a small hobby operating system written in C and x86 Assembly. It is a learning project focused on low-level programming, operating system development, and understanding how computers boot and interact with hardware.

## Features

- Custom command-line shell
- Filesystem commands such as `touch`, `cp`, `mv`, and `rm`
- ACPI-based system shutdown
- GRUB and Multiboot2 boot support
- UEFI boot support
- QEMU-based testing

## Building and Running

AOS is currently developed and tested in a Linux/WSL environment using GCC, NASM, GRUB tools, and QEMU.

## Project Status

AOS is an early-stage hobby project under active development. Features and hardware compatibility are still evolving.

## Goals

- Improve filesystem functionality
- Add file reading and writing commands such as `cat` and `echo`
- Support persistent file storage
- Continue developing a lightweight, DOS-inspired command-line operating system

**AOS is built for learning, experimentation, and the fun of creating an operating system from scratch.**
